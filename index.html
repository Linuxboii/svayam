An autogram is a sentence that correctly counts its own letters. Every number you write changes the counts you were writing about, so finding one is a search, not a sum. Type an opening and let it hunt.

How it searches

The sentence is a vector of 26 claimed counts. Rendering it to English and counting its letters gives a second vector. An autogram is a fixed point: the counts it claims are the counts it has.

Iterating that map directly falls into cycles almost immediately, so the worker moves only a random subset of letters toward their true counts each round, occasionally nudges one off by a step, and restarts from scratch when it stops improving. Letter totals for every number word are precomputed, so each candidate costs a few hundred integer additions — a few million candidates a second on a laptop. Every hit is recounted independently in the page before it is shown as true.
